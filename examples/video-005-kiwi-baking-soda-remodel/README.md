# Video 005 — Kiwi + Baking-Soda Smoothie Remodel

## Purpose

Validated close-remodel workflow for a viral kiwi / baking-soda smoothie reference adapted to:
- recurring Josh outdoor creator
- U.S.-audience signaling
- GUIDE funnel
- still-image-first Flow production

This example is especially important because one ingredient microtake repeatedly triggered Flow safety warnings and required an asset-level rescue strategy.

---

## Final sequence

1. Kiwi + baking-soda visual hook
2. Kiwi into blender
3. Baking soda into blender
4. Half lemon squeezed into blender
5. One glass of water poured into blender
6. Blend until smooth
7. Finished green smoothie payoff inside blender
8. Finished smoothie in one serving glass
9. Direct-to-camera explanation
10. U.S.-targeted GUIDE CTA

---

## Scene 1 — Hook

Visual:
- exactly one kiwi cut into two halves
- halves very close to camera
- baking soda above kiwi
- Josh in established outdoor environment
- one authentic U.S. flag in background, secondary to action

Original provocative pharmacy / Big Pharma framing triggered Flow safety.

Validated replacement copy:

> Put baking soda on kiwis and watch what happens. If you're in the U.S., you've probably never seen this simple kitchen trick.

Important scene-lock lesson:
Once the still looked correct, the successful animation did **not** re-describe the Texas / Southwest environment in detail.

Use:
- provided First Frame = actual physical set
- background = locked photographic plate
- animate only face / hands / powder / subtle flag movement / tiny camera drift

## Scene 2 — Kiwi into blender

Copy:

Validated setup:
- one empty blender
- one bowl / plate with approximately two cups kiwi
- medium recipe framing
- creator face smaller and less portrait-dominant

Action:
`BOWL TILTS → KIWI FALLS → SAME BLENDER`

Duration:
4 sec

## Scene 3 — Baking soda into blender

Copy:

> Then add a little baking soda.

This was the most difficult shot.

### Failure pattern

Flow repeatedly returned safety errors including:
- famous-person style detection
- reputation / current-events style warning

The warnings persisted even after the animation prompt was stripped of identity-heavy wording.

### Diagnosis

At that point the likely trigger was no longer just the text prompt.

Potential triggers:
- starting frame
- dominant face
- U.S. flag / national symbol
- character reference linkage
- Flow project / session state

### Validated rescue direction

Convert the microtake into a tight recipe insert:
- no dominant face
- face may be cropped completely
- no unnecessary flag in the insert
- hands + spoon + blender
- one small amount of plain white cooking powder
- one transfer only
- off-camera male voice acceptable

Physical chain:

`SPOON TILTS → POWDER FALLS → SAME BLENDER → SPOON ENDS EMPTY → HAND RETREATS`

Duration:
4 sec

Key lesson:
After multiple meaningful prompt simplifications, stop rewriting the same prompt. Change the **asset strategy**.

## Scene 6 — Blend

Copy:

> And blend that whole squad till it's smooth.

Still:
- lid securely on blender
- mixture still visibly chunky
- one hand near blender control
- blender OFF

Action:
- activate control once
- blender runs
- chunks circulate
- chunks gradually disappear
- mixture becomes uniform fresh green smoothie

Duration:
6 sec

Important:
Do not instantly jump from chunks to finished smoothie.

## Main lessons from Video 005

### 1. Scene lock got better when the animation prompt became simpler
A correct First Frame should be treated as the actual set, not as inspiration.

### 2. U.S. cues are useful but not mandatory in every shot
Keep them in hook / CTA / wider scenes. Remove them from fragile insert shots if needed.

### 3. Persistent Flow safety errors can be asset-level
When simplified text still fails, change crop / image / session rather than endlessly rewriting wording.

### 4. Hands-only microtakes are a practical rescue tool
They preserve recipe continuity without forcing a dominant recurring face into every ingredient transfer.

### 5. Off-camera voice can preserve the copy
If the shot is object-focused, the creator does not need visible lip sync for every microtake.

### 6. One action per fragile clip remains the strongest default
Kiwi, baking soda, lemon, water and blending each had their own simple state transition.

### 7. Finished drink explanation is more stable when drinking is omitted
Holding exactly one glass while speaking gives a cleaner payoff and CTA shot.
