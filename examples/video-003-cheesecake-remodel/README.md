## Major lessons

### 1. Continuous action beats cinematic staging
If the source performs a simple fluid move, model the physical chain instead of describing multiple scene beats.

### 2. One fragile action per clip
Do not combine bowl pour + baking transformation + chilling + finished-food reveal in one generation.

### 3. First-frame still must be pre-action
The image should show `about to pour`, `about to crack`, `about to scoop` rather than already completing the action.

### 4. Food-state continuity matters
Always state the exact current state:
- yogurt only
- egg + yogurt
- smooth batter
- batter + honey + vanilla
- filled ramekin
- baked cheesecake
- slice on plate

### 5. Keep GUIDE off-screen
The digital funnel product does not need to appear physically in the generated video.
