# Guided Mode Workflow

Use this when the user asks to work step by step.

## Rule zero

Only give the next actionable production step. Stop after that step.

## Sequence

1. Reference analysis
2. Character creation
3. Voice selection/profile
4. Character info/profile
5. Product master reference, if required
6. Scene 1 image
7. Scene 1 video
8. Scene 2 image
9. Scene 2 video
10. Continue alternating image/video until all scenes are complete
11. Assemble clips
12. Add captions/finishing edit
13. Review output and update skill

## Each image step should tell the user

- where to go
- what reference(s) to add
- aspect ratio
- exact prompt
- what to inspect before accepting the image
- when to stop

## Each video step should tell the user

- model
- aspect ratio
- exact duration
- ingredient image to use
- character/voice reference to use
- exact copy-paste prompt
- what to inspect before accepting the clip
- when to stop

## Do not

- dump future steps in advance
- require the user to reconstruct dialogue manually
- assume a step succeeded
- change character/product identity without saying so
